# AI助食网站 · 视觉设计建议文档

> 版本：V1.0（设计评审稿）
> 日期：2026-09-16
> 依据：《AI助食网站 PRD V1.0（MVP）》+ 参考配色卡「焦糖黄油」（SeSoul 8组有食欲配色）

---

## 一、设计定位

### 1.1 一句话风格定义

> **「焦糖黄油 · 暖食撞色」**——以焦糖棕、烤布丁橙、黄油黄三色为核心的有食欲暖调体系，辅以奶油底与薄荷解腻绿做冷暖撞色，复刻参考卡片的"大圆角 + 粗描边 + 手写点缀"贴纸感，让高校学生打开页面就"想吃饭"。

### 1.2 参考图拆解

| 参考元素 | 提取结论 | 在本项目中的用法 |
| --- | --- | --- |
| 色卡三色 | 黄油 `#F6C453`、烤布丁 `#D97A2B`、焦糖棕 `#6B3A1E` | 全站核心三色，承担"高亮 / 强调 / 文字"三层职能 |
| 大圆角卡片 + 粗描边 | 卡片为大圆角矩形，外侧粗黑描边包裹 | 菜品卡、窗口卡、榜单卡统一采用"奶油底 + 焦糖棕 2px 描边 + 大圆角" |
| 手写英文点缀（Color） | 流畅手写花体英文增加活泼感 | Logo 与标题角标使用 Caveat / 站酷快乐体手写点缀 |
| 扁平无衬线大标题 | 粗体方正无衬线、厚重醒目 | 页面标题统一 Noto Sans SC 900 加粗 |
| 信息分区排版 | 左对齐标题 + 右对齐色值，纵向流 | 菜品卡、榜单行统一"左侧信息 + 右侧数据"对齐规范 |

### 1.2 设计原则（4 条）

1. **先有食欲，再有信息**：暖色撞色第一眼传递"好吃"，信息层级第二眼传达"好用"。
2. **竖版优先**：所有页面以 375-480px 竖版为基准设计，桌面端居中成"手机外壳"式布局，不做复杂多栏。
3. **贴纸感与秩序感并存**：卡片可以有手写点缀和描边，但评分、价格、排名等数据必须清晰、工整、可扫描。
4. **撞色有节制**：每屏主撞色不超过 3 个色相（暖色 2 + 点缀 1），避免花哨影响可读性。

## 二、完整配色体系

### 2.1 核心色（焦糖黄油系）

| 色名 | 色值 | 角色 | 典型用途 |
| --- | --- | --- | --- |
| 焦糖棕 `caramel` | `#6B3A1E` | 品牌主色 / 深色文字 | Logo、标题、描边、深色区块、底部导航选中态 |
| 烤布丁橙 `pudding` | `#D97A2B` | 主行动色（CTA） | 「开始转盘」「提交点评」「进入卡片」等主按钮 |
| 黄油黄 `butter` | `#F6C453` | 高亮 / 强调 | 转盘亮区、标签选中、评分星、推荐页入口高亮 |
| 奶油白 `cream` | `#FFF8EC` | 页面底色 / 浅分区 | 全站背景、浅色分区、弹层背景 |
| 糖霜白 `sugar` | `#FFFFFF` | 卡片底色 | 菜品卡、详情卡、输入框 |

### 2.2 撞色点缀系（冷暖撞色）

| 色名 | 值 | 用途 |
| --- | --- | --- |
| 薄荷绿 `mint` | `#6FBF9F` | 「AI 营养」「健康建议」「减脂」语义；与焦糖系冷暖撞色，制造"解腻"视觉 |
| 番茄红 `tomato` | `#E4573C` | 「喜欢」「推荐！」「待点评提醒」情绪强调；禁止滥用，仅限点赞/点评/警示 |
| 蜜桃粉 `peach` | `#FFB38A` | 次级渐变、插画腮红、收藏态点缀 |

> 撞色公式：**焦糖暖（2 份） + 薄荷冷（1 份） + 白/奶油底（6 份）**。页面大面积使用奶油底与糖霜白，焦糖色用于结构和主按钮，薄荷绿仅出现在"营养/AI/健康"场景，番茄红仅在情绪化动作（喜欢、点评、待办）出现。

### 2.3 文字与中性色

| 色名 | 值 | 用途 |
| --- | --- | --- |
| 可可黑 `ink` | `#3B2A1E` | 主文字（正文、标题） |
| 奶茶灰 `mocha` | `#8A7A6B` | 次要文字、占位符、未选中态 |
| 奶咖浅 `latte` | `#E8D9C5` | 分割线、描边弱化、禁用态底 |
| 纯白 | `#FFFFFF` | 深色底上的反白文字 |

### 2.4 语义色映射（对接状态）

| 语义 | 色值 | 使用场景 |
| --- | --- | --- |
| 成功 / 推荐 / 加分 | 薄荷绿 `#6FBF9A` | 认证通过、营养达标、评分人数充足 |
| 警告 / 中等 | 烤布丁橙 `#D97A2B` | 候选池即将耗尽、评分人数偏少 |
| 错误 / 禁止 | 番茄红 `#E4573C` | 验证码错误、忌口冲突、点评失败 |
| 金 / 银 / 铜 | `#F2B33D` / `#B9C0C9` / `#C98A4B` | 排行榜 Top1/2/3 高亮 |

## 三、字体系统

| 层级 | 字体 | 字号 / 字重 | 用法 |
| --- | --- | --- | --- |
| 品牌标题 | Noto Sans SC Black（900） | 28-34px | 推荐页主标语、转盘页大标题 |
| 页面标题 | Noto Sans SC Bold（700） | 20-24px | 各页 H1 |
| 区块标题 | Noto Sans SC Medium/Bold | 16-18px | 卡片标题、榜单行菜名 |
| 正文 | Noto Sans SC Regular（400） | 14-15px | 描述、点评内容 |
| 辅助 | Noto Sans SC Regular | 12-13px | 标签、时间、评分人数 |
| 数字/英文 | Caveat（手写） | 22-28px | 装饰角标、榜单编号、转盘结果"好耶！" |
| 中文手写点缀 | 站酷快乐体（ZCOOL KuaiLe） | 24-32px | 广告轮播贴纸、空态引导文案 |

> 落地建议：中文主字体用 Noto Sans SC（可变字重 400-900，免费可商用）；手写英文用 Google Fonts `Caveat`；中文手写用 `ZCOOL KuaiLe`。正文行高 1.6，标题行高 1.3，数字用 tabular-nums 保证榜单对齐。

## 四、组件级设计规范

### 4.1 主按钮（CTA）

- 底色：烤布丁橙 `#D97A2B`，文字白色，胶囊圆角，高度 48-52px，加粗 700。
- 次级按钮：奶油底 + 2px 焦糖描边 + 焦糖文字。
- 按下态：整体下移 1px + 透明度 0.9，保留"贴纸按压"手感。
- 禁用态：`#E8D9C5` 底 + 米灰文字。

### 4.2 卡片系统

| 卡片类型 | 底色 | 描边 | 圆角 | 适用 |
| --- | --- | --- | --- | --- |
| 菜品卡 | 糖霜白 | 无（靠阴影） | 24px | 列表菜品卡 |
| 贴纸卡 | 奶油白/黄油黄 | 焦糖棕 2.5px | 24px | 转盘结果、榜单 Top3、功能入口（排行榜/转盘/卡片） |
| 窗口卡 | 奶油白 | 焦糖棕 2px | 20px | 所有菜品页窗口 |

### 4.3 标签系统（口味/忌口/快捷）

- 选中态：黄油黄底 + 焦糖棕描边 + 焦糖棕字；未选中：奶油白底 + 巧克力灰描边。
- 快捷点评标签（"太咸了/分量足/推荐！"）：选中变番茄红底白字，与主色区分。

### 4.4 星级评分

- 满分 5 星，星星统一黄油黄 `#F6C453` 填充，空星用 `#E8D9C5`。
- 半星按需（仅展示时），打分时整星交互。
- 评分数字用 Noto Sans SC Bold 18px，紧邻星阵右侧。

### 4.5 底部导航

- 高 64px + 安全区，奶油白底，上边缘 1px `latte` 分割线。
- 4 个 Tab：推荐 / 所有菜品 / AI 助手 / 个人。
- 选中态：图标与文字变焦糖棕 `#6B3A1E` + 顶部 3px 黄油黄小圆点；未选中：巧克力灰 `#8A7A6B`。

### 4.6 空态与加载

- 空态：奶油底 + 站酷快乐体手写文案（如"今天没菜？去转个盘吧！"）+ 黄油黄圆形插画底。
- 加载骨架：奶油白底色块闪烁（shimmer），圆角 24px，避免大面积菊花转圈。
- 转盘抽取中：黄油黄圆环旋转 + 底部"正在摇窗口…"。

## 四、页面级设计建议（按 PRD 8.1 逐页）

### 4.1 推荐页（RecommendationPage）

- **广告轮播**：整宽 240px 高圆角 20px，奶油底 + 焦糖棕描边，轮播指示点用黄油黄；每帧左上角一枚手写贴纸（如"新品！"）。
- **待点评入口**：番茄红圆点 + "上一餐待点评"手写贴纸，点击进入对应菜品点评页；完成后贴纸消失（满足"展示广告栏、待点评入口"）。
- **三入口（排行榜 / 转盘 / 卡片）**：三张"贴纸卡"竖排（竖版手机布局），每张左侧大图标、右侧箭头；转盘入口用黄油黄底 + 转盘图形，卡片入口用薄荷绿底 + 卡片图形，榜单入口用烤布丁橙底 + 奖杯图形——**用三色撞色区分三种决策模式**，一眼可辨。
- 若 PRD 补充广告位可沿用"横向滚动 + 自动轮播"。

### 4.2 登录 / 注册

- 上半屏：奶油底 + 大号手写品牌名"AI 助食"+ 旋转转盘插画；下半屏：糖霜白圆角面板（顶 32px 大圆角内收）承载手机号输入与验证码按钮。
- 验证码按钮：有效期内黄油黄，过期烤布丁橙，每日 5 次提示用巧克力灰小字。
- 登录按钮用烤布丁橙全宽胶囊；协议文案巧克力灰 12px。

### 4.3 偏好设置页

- 分区标题：焦糖棕 700 加粗 + 左侧 4px 黄油黄竖条。
- 标签多选："口味偏好（辣/酸/甜/咸/清淡）""忌口（香菜/葱/姜/蒜/海鲜/花生）"用 4.3 标签组件；限选 3~5 个时选满后未选标签变禁用灰。
- 饮食目标（增肌/减脂/维持）：三张单选贴纸卡，选中黄油黄底焦糖描边，未选中奶油白底。
- 过敏食材：自由输入框，提交后以番茄红标签回显。
- 底部"完成 / 跳过"：完成为主按钮，跳过为次级按钮。

### 4.4 所有菜品页（AllDishesPage）

- 顶部搜索框：奶油白底、圆角 100px、放大镜图标巧克力灰、300ms 防抖；搜索结果命中类型（菜名/食堂/窗口）用黄油黄小胶囊标注。
- 食堂标签：「荟贤 / 聚雅」胶囊 Tab，选中焦糖棕底白字。
- 楼层导航：左侧竖排"一层 / 二层 / 三层"，选中黄油黄圆角块 + 焦糖描边。
- 窗口卡片：右侧卡片流（奶油底 + 焦糖描边 24px 圆角），每卡含窗口名、楼层、菜品数；点击进入 WindowDishesPage。
- 无结果空态：手写文案"换个窗口找找？"。

### 4.5 窗口菜品页（WindowDishesPage）

- 顶部为窗口信息条：窗口名 + 楼层徽章（焦糖棕底白字圆角）。
- 菜品列表：复用菜品卡（糖霜白、阴影），卡内含图片、名称、价格（烤布丁橙加粗）、评分星 + 分数、标签行。
- 排序条：默认按综合评分降序，可选评分人数 / 最新 / 价格升序，用巧克力灰 Tab 胶囊切换。

### 4.6 菜品详情页（DishDetailPage）

- 大图区：顶部大图 + 底部奶油渐变小卡片（名称、食堂·窗口、价格、综合评分星）。
- 评分分布：五星柱状图（黄油黄柱），旁注评分人数；分布条用 `latte` 底 + `butter` 填充。
- 点评列表：点评气泡卡（糖霜白），含用户昵称、星级、快捷标签（番茄红/黄油黄）、文字、时间；"仅点评"状态用淡灰。
- 底部点评输入：吸底糖霜面板；星级黄油黄、快捷标签一键加、文字 200 字限；提交按钮烤布丁橙；24 小时限评提示用巧克力灰小字。
- 营养信息（如有）：薄荷绿区块徽章"参考值"，热量/蛋白质/脂肪/碳水四格小卡。

### 4.7 转盘页（RoulettePage）

- 第 1 层食堂选择：两张贴纸大卡（荟贤 / 聚雅），撞色区分（一张黄油黄、一张薄荷绿）。
- 第 2 层转盘：黄油黄与烤布丁橙交替扇形转盘，中心焦糖棕圆钮；外圈 3px 焦糖描边；下方候选范围提示"当前食堂全部窗口"。
- 停止后：贴纸卡展示"抽到 XX 窗口（X 楼）"，卡片右下角烤布丁按钮"查看窗口菜品"，左上角次级"再抽一次"；候选耗尽提示"本轮窗口已抽完，重新开始"。
- 抽中后进入 WindowDishesPage / DishDetailPage。

### 4.8 卡片页（SwipePage）

- 顶部：食堂徽章 + "已选 X 道 / 剩余 Y 道"（黄油黄数字加粗），进度条用黄油黄填充。
- 卡片区：固定尺寸（竖版约 280 × 400px），菜品卡大图 + 底部评分价格；右滑（喜欢）卡片斜向飞出示意绿，左滑（跳过）斜向飞出灰。
- 底部按钮三连：跳过（次级按钮）/ 喜欢（番茄红主按钮）/ 撤销（圆形图标按钮，仅最近一次可撤销）。
- 喜欢清单：顶部"喜欢清单"手写标题；超过 6 道出现黄油黄横幅"再筛一轮"进入二轮；二轮只用已喜欢卡片，结束后确认最终菜品（主按钮）或返回清单/重新开始（次级）。

### 4.9 排行榜（RankPage）

- Tab 切换：周榜 / 月榜，切换为胶囊 Tab，选中焦糖棕底白字；顶部可展示"更新于周一/月初 03:00"灰字。
- Top 3：金银铜奖牌徽章（金 `#F2B33D` / 银 `#B9C0C9` / 铜 `#D9A94E`）+ 大号贴纸卡加粗描边高亮；第 1 名卡片黄油黄底。
- 榜单行（4-10）：奶油白行 + 排名数字（焦糖棕 700）+ 菜名 + 窗口名 + 评分星 + 评分人数；行间距 8px。
- 评分人数系数：评分人数 < 50 时数字旁加"样本少"橙黄色警示，点击解释系数规则（防刷榜说明）。
- 点击行进入菜品详情页，详情页提供点评入口（满足"榜单可进入详情并评价"）。

### 4.10 AI 助手页（AIAssistantPage）

- 顶部横幅：薄荷绿渐变 + 焦糖棕"AI 营养师"标题 + 手写"拍照识别 · 参考值"。
- 快捷入口：「分析今日饮食」「拍照识菜」（PRD 7.1 已扩展为拍照识别）——两个大黄油底圆角卡。
- 对话气泡：用户气泡右对齐焦糖棕底白字；AI 气泡左对齐奶油底焦糖字；营养分析结果以结构化卡片（进度条 + 饼图）插入对话流。
- 营养分析图表：总热量进度条（黄油黄）、三大营养素占比饼图（薄荷绿/黄油黄/烤布丁橙三色）、完成率卡片；数据"参考值"徽章薄荷绿。
- 免责声明：底部小字巧克力灰"AI 建议仅供参考"。

### 4.11 个人中心 / 我的点评

- 头部：奶油底 + 头像（黄油黄圆形底）+ 昵称 + 偏好标签展示（2-4 枚）。
- 我的点评列表：按时间倒序，卡片含菜品小图 + 星级 + 快捷标签 + 可编辑/删除；删除为次级操作（需确认弹窗）。
- 偏好设置入口：个人中心右上角"编辑"跳转偏好页。
